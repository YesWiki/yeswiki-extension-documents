# yeswiki-extension-documents

 - [English](#english)
 - [Français](#français)

## English

[YesWiki](https://yeswiki.net/) extension. Attaches a collaborative document (Etherpad, HedgeDoc, Memo, OnlyOffice) to an entry and shows it in the page.

### Authors

 - all contributors indicated on this page : <https://github.com/YesWiki/yeswiki-extension-documents/graphs/contributors>

### Install

On your wiki's `/admin/updates` screen, install the `documents` extension: installing it switches it on. From a shell: `./yeswicli extension:enable documents`. Version `5.x` is for YesWiki Ectoplasme, `4.x` for Doryphore.

### Usage

Usage help is on your wiki's `/doc` page once the extension is on, and here: https://github.com/YesWiki/yeswiki-extension-documents/blob/ectoplasme/docs/en/README.md
